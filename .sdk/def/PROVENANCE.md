## Why this SDK exists

It is on the admin repository's **vergleich** list: SDKs built with the Voxgig
toolchain to compare it with the generators on voxgig.com/sdk/comparisons, one
API per generator. This one is compared with **OpenAPI Generator**.

- **Compared with:** lob/lob-typescript-sdk, `@lob/lob-typescript-sdk` 1.4.2, generated with OpenAPI Generator 5.3.0 (`.openapi-generator/VERSION`). Lob's Python, Ruby, Java, Go and PHP SDKs are OpenAPI Generator output too.
